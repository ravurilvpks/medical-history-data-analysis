# medical-history-data-analysis
Healthcare data analysis using MySQL to explore patient-related trends and generate insights.
**Project Overview**
This project was completed based on client requirement PRSQ-01-MEDICAL DATA HISTORY.
The objective was to work with medical data using MySQL and solve 34 SQL queries provided by the client.
**Database and Tables**
Database:project_medical_data_history
**Table used:**
•	Patients
•	Admissions
•	Doctors
•	Province_names
**Data validation**
Before executing the client queries, basic data validation was performed.
The following checks were completed:
•	Table structure verification
•	Record count verification 
•	NULL values checks
•	Duplicate checks
•	Table relationship checks
•	Date validation
